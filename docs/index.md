## Pensado para documentación técnica

<div class="tx-cards" markdown>

- **Lectura cómoda**

    Source Serif 4 para el texto y los títulos; Manrope para menús, tablas y
    pies de figura; JetBrains Mono para el código.

- **Claro y oscuro**

    Un tema oscuro propio, no una inversión del claro. La preferencia del
    sistema se respeta y se recuerda.

- **Personalizable**

    Dos colores y, si se quiere, otras fuentes. El resto sale de una sola hoja
    de estilos con variables.

</div>
